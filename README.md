# PureVision VLN｜多目纯视觉语言导航

[English](README.en.md)

这是一个持续更新的多目纯视觉视觉语言导航展示项目。系统通过视觉观测与自然语言指令，在真实空间中完成跨区域通行、语义目标寻找和结构化环境通过。

通过少量场景级示范数据进行适配，系统即可学习空间关系、语言目标与连续行动之间的对应，并在新指令与相近环境中展现实用的理解与迁移能力。

## 当前内容

- 室内跨区域通行：客厅到厨房。
- 语义目标寻找：床、木制衣柜、饮水机。其中饮水机包含开灯与未开灯两种测试场景；模型仅使用开灯场景数据训练。
- 结构化通行：穿越闸机。

## 仿真评测

真机结果之后提供 7 条代表性闭环仿真评测视频，覆盖室外草地绕行/穿越、室内跨区域导航、精确 STOP，以及起始朝向偏转 ±75° 时的恢复能力。仿真视频与真机录像在页面中分区展示，并标注 SPL、终点误差和碰撞数。

这些视频是模型训练完成后的在线闭环评测记录，不是训练样本。模型持续预测局部航点与 STOP，控制器执行预测结果。
